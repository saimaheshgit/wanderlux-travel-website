# WanderLux Travel Agency — ICT502 Assessment 2

## Project contents
- `index.html` — Home page with rotating destination banner and package highlights
- `destinations.html` — Destination cards and agency services
- `calculator.html` — Interactive trip cost calculator
- `appointment.html` — Appointment request form
- `about.html` — Agency overview, mission and service values
- `contact.html` — Contact details, map and general enquiry form
- `assets/style.css` — Responsive layout, components and visual styling
- `assets/script.js` — Mobile navigation, rotating banner, scroll reveals and calculator

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser. For best results, use VS Code Live Server or another local static server.
3. Test every navigation link, the calculator and the form validation.

## Important configuration before live deployment
The forms use FormSubmit as a simple form-to-email service. In `appointment.html` and `contact.html`, replace:
`https://formsubmit.co/REPLACE_WITH_YOUR_EMAIL`
with the email address you control, then complete the provider's email activation/verification step. Test with non-sensitive sample data. Do not collect sensitive personal information in this demonstration project.

All phone, email and address details shown are illustrative. Replace them with verified details if this becomes a real business site. The calculator uses sample planning rates, not live supplier prices. Images are loaded from Unsplash URLs and therefore require an internet connection.

## Publish with GitHub Pages
1. Create a GitHub repository for the project.
2. Upload the extracted files and folders, keeping the folder structure unchanged.
3. In repository Settings, open Pages.
4. Select deployment from the main branch and the root folder, then save.
5. Wait for the deployment URL shown by GitHub Pages. Add that real URL to the report before submission.
6. Re-test the live pages and forms. GitHub Pages hosts static files; it does not itself process email submissions.
